# ShopEasy CRM

Sistema de gestión de relaciones con clientes (CRM) para una tienda de comercio electrónico ficticia.

## Objetivo

Centralizar la información de clientes, pedidos, productos e interacciones para mejorar la atención al cliente y facilitar la toma de decisiones.

## Tecnologías

- C#
- ASP.NET Core MVC
- MySQL
- Entity Framework Core
- HTML, CSS y Bootstrap
- Git y GitHub

## Estructura del proyecto

- `Backend/`: lógica de negocio, modelos y controladores de la aplicación.
- `Frontend/`: recursos y componentes de la interfaz de usuario.
- `README.md`: documentación del proyecto.
